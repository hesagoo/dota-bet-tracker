# Выпуск версии 1.2.0 — что делать вам на Windows

Версия в `version.py` уже 1.2.0, `installer\app_version.iss` обновлён. Ничего не опубликовано.

## 1. Сборка и проверка (в папке проекта)
1. `py -3.12 -m pip install -r requirements.txt` (если ещё не ставили)
2. Проверка перед сборкой: `py -3.12 -m unittest tests.test_core tests.test_updater` и `py -3.12 tests\test_appearance.py`
3. `build_exe.bat` — соберёт `dist\DotaBetTracker\DotaBetTracker.exe`
4. Запустите `dist\DotaBetTracker\DotaBetTracker.exe`, пройдите все страницы, откройте «Настройки → Стиль и эффекты».

## 2. Установщик
Откройте `installer\DotaBetTracker.iss` в Inno Setup → Compile (F9) → `installer\Output\DotaBetTracker-Setup-1.2.0.exe`.
Установите его на чистую папку и убедитесь, что программа запускается и данные на месте.

## 3. Файлы релиза
Папка `release\1.1.0\` (с `files.json`) должна лежать в проекте — по ней считается дельта.
`py -3.12 tools\make_release.py --notes "Новое оформление: тёмное стекло, прозрачность, свечение" --notes "Настройки внешнего вида"`
Появится `release\1.2.0\`: `latest.json`, `files.json`, полный ZIP и дельта от 1.1.0.

## 4. GitHub (только после вашей проверки)
GitHub Desktop: Changes → сообщение «Версия 1.2.0: новое оформление» → Commit to main → Push origin.
Releases → Draft a new release → тег `v1.2.0` → загрузите 4 файла из `release\1.2.0\` и установщик `DotaBetTracker-Setup-1.2.0.exe` → Publish release.

## ВАЖНО: приватный репозиторий и автообновление
Автообновление скачивает файлы без пароля. Из **приватного** репозитория релизы без токена не скачиваются (ответ 404), поэтому «Проверить обновления» у вас работать не будет.
Варианты: (а) отдельный публичный репозиторий только для релизов (например, `dota-bet-tracker-releases`), исходники остаются в приватном; в «Адрес обновлений» вписать адрес публичного;
(б) сделать основной репозиторий публичным (вы просили этого не делать). Рекомендую вариант (а).
