# Dota Bet Tracker

**Умный калькулятор и инструмент аналитики для ставок.**

Приложение для Windows с удобным интерфейсом, настраиваемым оформлением и встроенной системой обновлений.

## Возможности

- **Аналитика:** инструменты для работы с данными и результатами матчей.
- **История:** просмотр и управление сохранёнными записями.
- **Статистика:** графики и сводная информация.
- **Настройка интерфейса:** графитовая, чёрная и светлая темы.
- **Визуальные эффекты:** прозрачность, свечение и анимации.
- **Обновления:** проверка новых версий и установка прямо из приложения.

## Установка

1. Открой раздел [Releases](https://github.com/hesagoo/dota-bet-tracker/releases).
2. Скачай последнюю версию установщика `DotaBetTracker-Setup`.
3. Запусти установщик и следуй инструкциям.
4. Открой приложение.

## Обновления

Программа самостоятельно проверяет наличие новых версий. Когда обновление доступно, пользователь получает уведомление и сам решает, устанавливать его или нет.
