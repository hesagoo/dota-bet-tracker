# Dota Bet Tracker — личный учёт ставок на Dota 2

Тёмное (и светлое) приложение для Windows: банк, ставки и экспрессы, история, аналитика, резервные копии.
Все данные хранятся только на вашем компьютере, интернет не нужен.

## 1. Что установить (один раз)
1. **Python 3.11 или новее** — https://www.python.org/downloads/ . При установке поставьте галочку **«Add python.exe to PATH»**.
2. Распакуйте папку `dota_bets` куда удобно (например, `C:\DotaBets`) и дважды щёлкните **`setup.bat`**.

## 2. Как запустить
Дважды щёлкните **`run.bat`**. При первом запуске программа спросит начальный банк (можно 0 и изменить позже).

## 3. Как собрать EXE, ярлык и установщик
- **EXE:** дважды щёлкните **`build_exe.bat`** → `dist\DotaBetTracker\DotaBetTracker.exe` (без консоли, с иконкой). Копируйте всю папку `DotaBetTracker`. Python для работы EXE не нужен.
- **Ярлык на рабочем столе:** `create_shortcut.bat` (после сборки EXE).
- **Установщик:** установите бесплатный Inno Setup, откройте `installer\DotaBetTracker.iss`, нажмите Compile — получится `installer\Output\DotaBetTracker-Setup-<версия из version.py>.exe` (ставится без прав администратора, есть ярлык на рабочем столе).
- **Своя иконка:** замените файл `assets\icon.ico` на свой ICO (лучше с размерами 16–256 px) и снова запустите `build_exe.bat`. Стандартную иконку можно создать заново: `python tools\make_icon.py`.
- После любых изменений в программе: меняете `version.py` (номер версии) и снова `build_exe.bat`.
Данные хранятся отдельно (`%APPDATA%\DotaBets`) и от пересборки или переустановки не зависят.

## 3b. Внешний вид (версия 1.2.0)
Настройки → «Оформление и формат» и «Стиль и эффекты»: тема (Графит / Чёрная / Светлая), акцентный цвет, прозрачность панелей
(готовые уровни и ползунок), свечение, след курсора, анимации. Всё применяется сразу и сохраняется после перезапуска.
«Размытие фона Windows 11» — экспериментальная функция: включается после перезапуска и только в Windows 11; если система её не поддерживает, программа работает с обычным фоном.
Список изменений по версиям — `CHANGELOG.md`.

## 3a. Обновления и помощник по ставке
- Обновления из интерфейса: Настройки → «О программе и обновления» (как настроить и выпускать — `docs\UPDATES.md`).
- «Помощник по ставке» на дашборде: 3 / 4 / 5% от доступного банка (без ставок «в игре»), округление до 50, не выше 5%; кнопка переносит сумму в форму ставки.
- План будущей ИИ-аналитики матчей: `docs\ARCHITECTURE_MATCH_ANALYTICS.md`.

## 4. Где хранятся данные
`C:\Users\<Вы>\AppData\Roaming\DotaBets\` — файл `bets.db` (всё: ставки, банк, настройки) и папка `backups`.
Быстро открыть: Настройки → «Открыть папку». Данные сохраняются мгновенно после каждой операции.

## 5. Резервные копии
- Автоматически: при запуске, при выходе и раз в 30 минут (если были изменения). Хранится последних 15 (меняется в настройках).
- Вручную: Настройки → «Создать копию сейчас» или «Сохранить копию как…» (например, на флешку).
- Восстановление: Настройки → «Восстановить из копии…». Перед восстановлением текущие данные автоматически сохраняются отдельной копией.
- Если основной файл повреждён, программа сама возьмёт последнюю копию.

## 6. Как пользоваться
- **Ctrl+N** или «＋ Добавить ставку»: матч, сумма, коэффициент, результат — всё. Турнир, дата и комментарий — в «Дополнительно».
  Экспресс: выберите тип «Экспресс» и укажите итоговый коэффициент.
- Ставки «Ожидает» закрываются одним кликом на дашборде (Выигрыш / Проигрыш / Возврат).
- **История**: сортировка по заголовкам, поиск, фильтры, двойной клик — редактирование, правый клик — быстрые действия, экспорт в Excel/CSV.
- **Аналитика и дашборд** считаются за выбранный сверху период; «Всё время» — общая статистика.
- **Банк**: пополнение, вывод, изменение начального банка (записывается в историю, прибылью не считается).

## 7. Правила расчёта
Выигрыш: прибыль = сумма × (коэф − 1); проигрыш: −сумма; возврат и ожидание: 0.
Текущий банк = начальный + пополнения − выводы + результат ставок. Доступно = банк − сумма ожидающих ставок.
Win Rate = выигрыши / (выигрыши + проигрыши). ROI = чистая прибыль / сумма выигравших и проигравших ставок.
«% банка» = доля ставки от банка на момент её совершения. Все деньги считаются через Decimal (без ошибок округления).

## Для разработчика
Проверка расчётов и обновлений: `python -m unittest tests.test_core tests.test_updater`. Сквозная проверка интерфейса: `python tests/test_ui_flow.py`.
Скриншоты на тестовых данных: `python tests/ui_smoke.py <папка>` (реальные данные не трогаются).
